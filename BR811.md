# BR811 — fictional sound chip for Furnace Tracker

BR811 is the sound chip of **Ompreza**, a fictional 8-bit console from 1984 (third generation).
Both were designed by **Evolution BR811**. This fork adds the chip to
[Furnace Tracker](https://github.com/tildearrow/furnace) as a new system, without changing any existing chip.

> BR811 and Ompreza are fictional. No real hardware exists. The emulation core is original code.

| Audio | BR811, 5 channels |

## The BR811 chip

- 5 channels, clock 6,420,000 Hz (same as the CPU), 4-bit volume (0–15) per channel
- 12-bit period (0–4095), pitch = clock / (57 × (P + 1)); lowest note is A-0 (27.5 Hz). The divider of 57 (instead of 114) gives every note twice as many tuning steps, so high notes stay in tune
- Each channel can switch at any time between **Wave A**, **Wave B** and **white noise**
- Channel 5 can also play **7-bit PCM** from cartridge ROM
- Mono output (mix of the 5 channels)

### Waveforms

| Wave | Steps | Output values (0–15) |
| --- | --- | --- |
| Wave A (melodic, own take on a pulse) | 8 | 0 0 12 14 14 14 12 0 |
| Wave B (full, metallic, bass-friendly) | 16 | 0 0 15 15 15 15 15 15 15 0 0 0 15 15 0 0 |

Both waves have a single fixed shape (no duty-cycle register).

### Noise

Per-channel 16-bit LFSR white noise (feedback from bits 0 and 3). The rate is picked from fixed values:

| Code | Rate | About |
| --- | --- | --- |
| 000 | clock / 512 | 12,539 Hz |
| 001 | clock / 1024 | 6,270 Hz |
| 010 | clock / 2048 | 3,135 Hz |
| 011 | linked to the channel's own period | follows the note |
| 100 | clock / 256 | 25,078 Hz (open hat, cymbals) |
| 101 | clock / 128 | 50,156 Hz (closed hat) |

### PCM (channel 5)

- 7-bit linear, 8,000 Hz at C-4 (period 430); the note changes the playback speed
- Read from cartridge ROM by DMA, 16 CPU cycles stolen per byte
- Up to 4 KB per sample, in 16-byte blocks; the whole sample can loop

### Registers

| Index | Register | Bits |
| --- | --- | --- |
| channel × 3 + 0 | Control | 7-6 mode (0 Wave A, 1 Wave B, 2 noise, 3 PCM on channel 5); 3-0 volume |
| channel × 3 + 1 | Period low | 7-0 |
| channel × 3 + 2 | Period high + noise | 6-4 noise rate; 3-0 period high bits |
| 15 | PCM address low | |
| 16 | PCM address high | |
| 17 | PCM length | (value + 1) × 16 bytes |
| 18 | PCM control | bit 0 play; bit 1 loop |

## Using it in Furnace

1. New system → category **Specialized** → **Ompreza (fictional, BR811)** (or pick **BR811** in the chip list).
2. Create an instrument of type **BR811**.
3. In **Macros**, the **Waveform** macro (0–7) chooses the sound: 0 Wave A, 1 Wave B, 2 noise /512,
   3 noise /1024, 4 noise /2048, 5 noise linked to pitch, 6 noise /256, 7 noise /128.
   The effect `20xx` does the same from the pattern.
4. For PCM, open the **Sample** tab, tick **Use sample** and pick a sample, then play it on channel 5.

## Building

Same as Furnace (see `README.md`). On Windows use the MSYS2 **MINGW64** shell with cmake and ninja.
