# SID register map

these are mapped at $D400 on C64.
ADCs are connected to paddle pins on a C64's joystick port.

## Channel 1
```
    7 .... 0
00  xxxxxxxx   freq low
01  xxxxxxxx   freq high
02  xxxxxxxx   pulse width low
03  ....xxxx   pulse width high
04  x.......   noise on
    .x......   pulse on
    ..x.....   saw on
    ...x....   triangle on
    ....x...   test (mute output)
    .....x..   ring mod
    ......x.   osc sync
    .......x   gate (key on)
05  xxxx....   attack rate
    ....xxxx   decay rate
06  xxxx....   sustain level
    ....xxxx   release rate
```

## Global

```
    7 .... 0
15  .....xxx   cutoff low
16  xxxxxxxx   cutoff high
17  xxxx....   resonance
    .....x..   ch3 filter
    ......x.   ch2 filter
    .......x   ch1 filter
18  x.......   ch3 mute
    .x......   high pass
    ..x.....   band pass
    ...x....   low pass
    ....xxxx   output volume
19  xxxxxxxx   ADC 1
1A  xxxxxxxx   ADC 2
1B  xxxxxxxx   ch3 osc debug
1C  xxxxxxxx   ch3 env debug
```

- osc/env debug registers are read-only.
