# Philips SAA1099

this was used by the Game Blaster and SAM Coupé. it's pretty similar to the AY-3-8910, but has stereo sound, twice the channels and two envelopes, both of which are highly flexible. the envelopes work like this:
- an instrument with envelope settings is placed on channel 2 or channel 5
- an instrument that is used as an "envelope output" is placed on channel 3 or channel 6 (you may want to disable wave output on the output channel)

## effects

- `10xy`: **set channel mode.**
  - `x` toggles noise.
  - `y` toggles square.
- `11xx`: **set noise frequency.**
  - `0`: high
  - `1`: mid
  - `2`: low
  - `3`: use frequency of channel 1 or 4 (depending on where the effect is placed).
  - this effect affects either the first 3 or last 3 channels, depending on where it is placed.
- `12xx`: **setup envelope.** this is a bitmask.
  - bit 7 toggles the envelope.
  - bit 6 toggles whether the software timer will strobe the envelope activation bit.
    - this is useful to produce PWM effects.
  - bit 5 toggles whether to use a software timer or lock to the frequency of channel 2 or 5.
    - in the timer mode, Furnace will periodically knock the envelope register to cycle envelopes.
  - bit 4 sets the envelope resolution.
  - bits 1 to 3 set the envelope shape:
    - `000`: always off
    - `001`: always on
    - `010`: down
    - `011`: down loop (saw)
    - `100`: up down
    - `101`: up down loop (triangle)
    - `110`: up then off
    - `111`: up loop (reverse saw)
  - bit 0 sets whether the right output will mirror the left one.
  - this effect affects either the first 3 or last 3 channels, depending on where it is placed.
  - the envelope pitch depends on the mode:
    - +3 octaves in timer strobe mode.
    - ±0 octaves in timer mode.
    - -3 octaves in channel 2/5 mode.
    - if strobing:
      - add 1 octave for shapes `000`-`011`.
      - if mirror is on, one output channel will be an octave higher.
    - if not strobing:
      - add 1 octave if the low resolution bit is on.
      - subtract 1 octave if the shape is a triangle wave.
